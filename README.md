# 쉐도잉 랩 (Shadowing Lab)

러시아어·영어 문장을 **듣고 → 따라 말하고 → 익히는** 1인용 웹앱입니다.
빌드 도구 없이 **단일 HTML 파일**로 동작하고, 아이폰 Safari와 홈 화면 추가에서 바로 쓸 수 있습니다.

- 앱 파일: `index.html` (아이콘·스타일·스크립트 모두 포함, 외부 요청 없음)
- 복사본: `/workspace/downloads/shadowing.html` (같은 파일)
- 홈 화면 아이콘 원본: `icon-180.png` (HTML 안에 base64로 내장되어 있어 없어도 동작)
- 검증 스크린샷: `preview/`

---

## 1. 바로 쓰는 법

**PC** — `index.html`을 브라우저로 열면 끝.

**아이폰**
1. Safari에서 페이지를 엽니다(또는 파일을 열어 봅니다).
2. 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 `쉐` 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

> 마이크 녹음은 보안 정책상 **https 주소** 또는 localhost에서만 동작합니다.
> GitHub Pages(https)나 Vercel 같은 https 주소로 열면 그대로 됩니다.

## 2. 기능

### 언어 · 콘텐츠
- **🇷🇺 러시아어 / 🇺🇸 영어** 탭 전환. 언어마다 색 테마가 바뀝니다(러시아어 로즈, 영어 블루).
- 카테고리
  - 🎬 **영화·드라마 명대사** — 언어별 8문장
  - ☕ **기초 일상 대화** — 언어별 8문장
  - ✏️ **내 문장** — 직접 추가/수정/삭제, 무제한 (카드 우측 상단 **＋** 로 계속 추가)
- 각 문장에는 **원어 / 발음(한글) / 한국어 뜻**이 모두 들어 있습니다.
  러시아어는 한글 발음 아래에 **로마자 표기**도 함께 보여 줍니다.

### 쉐도잉 플레이어
- **원어민 발음 재생**: Web Speech API(`ru-RU` / `en-US`). 기기에 설치된 음성 중 해당 언어 음성을 자동 선택하고, 그 언어 음성이 없으면 상단에 설치 안내 문구를 띄웁니다.
- **속도** 0.6x · 0.75x · 0.9x · 1.0x · 1.15x
- **반복** 1회 · 3회 · ∞(무한). 재생 중에 바꾸면 새 설정으로 다시 시작합니다.
- **자막 3종 독립 토글**: 원문 / 발음 / 뜻. 셋 다 끄면 "듣기만" 모드로 바뀌고, 들리는 소리에 집중하는 화면이 나옵니다.
- **내 목소리 녹음 & 비교**: 마이크로 따라 말한 뒤 바로 재생해 원어민 음성과 번갈아 들을 수 있습니다. 마이크를 쓸 수 없는 환경에서는 이유와 해결 방법을 토스트와 시트 안내로 보여 줍니다.
- **완료 체크 / 진도**: `익혔어요` 버튼으로 문장을 완료 표시하고, 카드 하단에 `3 / 8 익힘`, 상단에 **오늘 연습한 문장 수**가 표시됩니다.

### 저장 (localStorage)
키: `shadowing-lab-v1`
- 선택한 언어·카테고리·문장 위치
- 속도·반복·자막 토글 상태·테마(다크/라이트)
- 완료 표시, 오늘 연습한 문장(날짜가 바뀌면 자동 초기화)
- 내가 추가한 문장

브라우저 데이터를 지우면 함께 사라집니다. 초기화하려면 브라우저 설정에서 이 사이트의 데이터를 삭제하세요.

## 4. 아이폰 음성 설정 (중요)

TTS 품질은 기기에 설치된 음성에 달려 있습니다.

1. **설정 › 손쉬운 사용 › 콘텐츠 말하기 › 음성 › 러시아어**
2. 원하는 음성(예: Milena)을 눌러 다운로드
3. 같은 방법으로 **영어(미국)** 음성도 확인

음성이 없으면 앱이 카드 위에 안내 문구를 띄웁니다. 재생이 안 되면 음량과 무음 모드도 확인해 주세요.

  - `gh-pages` — 실제로 서비스되는 브랜치 (현재 `main`과 같은 내용)
  - `preview/`는 `.gitignore`에 넣어 저장소에 올리지 않습니다.
- 아이폰 Safari로 주소를 열고 **홈 화면에 추가**

### 수정한 내용을 반영하려면

서비스는 `gh-pages` 브랜치를 보고 있으므로, 고친 뒤 **두 브랜치 모두** 올립니다.

```bash
cd shadowing-app
git add -A && git commit -m "문장 추가"
git push origin main
git push origin main:gh-pages
```

푸시 후 1~2분 안에 GitHub Pages가 다시 빌드되고, 위 주소에 바로 반영됩니다. (빌드 상태는 저장소 **Actions › pages build and deployment** 에서 확인)

> 참고: 예전 문서에 적힌 `shadowing-lab` 저장소는 만들지 않았습니다. 실제 저장소 이름은 `dudu-shadowing`입니다.

```
shadowing-app/
├─ index.html      ← 앱 본체 (HTML + CSS + JS + 아이콘 base64)
├─ README.md
├─ icon-180.png    ← 홈 화면 아이콘 원본(참고용)
└─ preview/        ← 검증 스크린샷
   ├─ 01-main-ru.png     러시아어 · 다크
   ├─ 02-main-en.png     영어 · 일상 대화
   ├─ 03-light.png       라이트 테마
   ├─ 04-custom-empty.png 내 문장(비어 있음) + 추천 문장
   ├─ 05-add-sheet.png   문장 추가 시트
   ├─ 06-custom-card.png 내 문장 카드(수정/삭제 버튼)
   ├─ 07-recording.png   녹음 시트
   ├─ 08-mic-fallback.png 마이크 없을 때 안내
   ├─ 09-listen-mode.png 자막 모두 끈 듣기 모드
   ├─ 10-long-text.png   긴 문장 처리
   ├─ 11-small-320.png   320px 폭
   ├─ 12-desktop.png     데스크톱(중앙 정렬)

```

`index.html` 안에서:
- 문장 추가/수정: `var CONTENT = { ru: {...}, en: {...} }` 의 `items` 배열
  (`text` 원어, `pron` 한글 발음, `ko` 뜻, `tag` 출처/상황, 선택 `lat` 로마자)
- 러시아어 로마자 표기: `var LAT = { "ru-m1": "...", ... }`
- 색 테마: `CONTENT[언어].accent`, `accent2` / CSS 변수 `--accent`
- 저장 키 변경: `var LS_KEY = "shadowing-lab-v1"`

## 7. 검증 결과

헤드리스 Chromium(Playwright)으로 실제 렌더링·조작을 확인했습니다.

- **해상도**: 375×812(iPhone X/13 mini 기준), 390×844, 414×896, 375×667(iPhone SE), 320×680 — 가로 스크롤·겹침 없음, 화면 높이가 작으면 문장 영역만 내부 스크롤
- **확인한 동작**
  - 언어/카테고리 전환, 카테고리별 위치 기억
  - 자막 3종 개별 토글, 모두 끄면 듣기 전용 화면
  - 속도 5단계, 반복 1/3/∞ (가짜 음성 엔진으로 1회=1발화, 3회=3발화, ∞=계속 재생 후 정지 확인)
  - 재생 중 속도 변경 시 새 속도로 재시작, 문장 이동 시 즉시 정지
  - 완료 체크 → `오늘` 카운트 즉시 반영, 새로고침 후에도 유지
  - 내 문장 추가/수정/삭제(두 번 눌러 삭제), 언어별로 따로 저장
  - 다크/라이트 전환, 아이콘·문구 갱신
  - 마이크가 없는 환경에서 안내 메시지 표시(토스트 + 시트 문구)
- **JS 오류**: 없음 (`window.__errors` 빈 배열)
- **미확인(실기기 필요)**: 실제 아이폰에서의 TTS 음성 음질, 마이크 녹음 권한 흐름, 홈 화면 아이콘 표시
  — 헤드리스 환경에는 음성 엔진과 마이크가 없어 해당 경로는 안내(fallback) 동작으로만 확인했습니다.

## 8. 참고

- 화면 조작: `Space` 재생/정지, `←`/`→` 이전/다음 문장, `Esc` 시트 닫기 (데스크톱)
- iOS 사파리에서 첫 재생은 반드시 **재생 버튼을 직접 눌러** 시작해야 합니다(자동 재생 정책).
- 앱은 네트워크를 쓰지 않습니다. 모든 데이터는 기기 안(localStorage)에만 저장됩니다.
